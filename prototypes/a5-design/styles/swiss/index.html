Pixels before frameworks

In college I drew everything myself in Turbo C: pick a video mode, write bytes to memory, see colour. No library, just the machine.

/* mode 13h: 320x200, 256 colours */
unsigned char far *vga = (unsigned char far *)0xA0000000L;
void plot(int x, int y, unsigned char c) {
    vga[y * 320 + x] = c;
}

That one line of arithmetic is still the best explanation of a framebuffer I know.
